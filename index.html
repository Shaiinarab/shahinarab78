How this page works

One static page, one public API, zero trackers. The directory is rebuilt in your browser on every visit, so new repositories show up without a redeploy.

  • Public GitHub data only — forks and this page's own repo are filtered out.
  • If the API is rate-limited or offline, a cached snapshot from your last visit keeps the page useful.
  • No cookies, no analytics, no third-party scripts.
