How I work

Projects improve through small, verifiable loops rather than broad, untested rewrites.

01 — Establish the baseline

Read the code, run the available checks, and make blockers visible before adding scope.

02 — Ship a bounded improvement

Turn one clear acceptance target into a reviewable, testable change.

03 — Learn and iterate

Capture evidence from checks and reviews, then feed it into the next focused story.
